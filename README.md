## Що це

Програма тримає у вашій мережі дзеркало оновлень ESET: сама опитує сервери,
завантажує бази, розкладає їх по папках і FTP та роздає власним вбудованим
сайтом. Антивіруси на робочих місцях оновлюються з неї, а не кожен окремо
з інтернету.

**Навіщо:**

* **Трафік.** База важить понад 2 ГБ. Двадцять комп'ютерів тягнуть її двадцять
  разів — дзеркало качає один раз.
* **Машини без інтернету.** Ізольований сегмент оновлюється з дзеркала
  всередині мережі.
* **Незалежність від збоїв.** Ліг сервер ESET — програма сама візьме інший,
  зі списку у вісімнадцять адрес.

## Головне

* **Портативна** — один `.exe`, усе поруч із ним. Ані встановлення, ані запису
  в реєстр, ані залежностей.
* **Ключ не обов'язковий** — без нього закрита лише закачка з офіційних
  серверів; діагностика, чужі дзеркала й роздача працюють.
* **Кілька місць одночасно** — папки і FTP; файл завантажується раз
  і розкладається в усі.
* **Працює місяцями без нагляду** — таймер, роздача, журнал по добах
  і індикатор стану, за яким видно все без читання логів.

Розрахована на корпоративні продукти ESET — Endpoint Antivirus / Endpoint
Security та File Security: саме в них є поле «сервер оновлень».

## Попередження антивірусів

**Частина антивірусів лається, і це очікувано.** На VirusTotal програму
позначають приблизно 13 рушіїв із 71. Жоден не називає конкретної родини -
усі вердикти евристичні: «anomalous», «MachineLearning/Anomalous»,
«Generic Suspicious», «Trojan-Downloader.Autoit.gen». Загальний ярлик так
і звучить: `trojan.anomalous/autoit`.

Причин три, і всі технічні:

* **збірка AutoIt.** У exe вшито інтерпретатор, той самий, яким користуються
  й автори шкідливого. Правила ловлять саму обгортку, а не поведінку;
* **програма справді качає файли з інтернету й запускає власні копії**
  (помічники `/probe` і `/ftpput`). Для поведінкової евристики це буквально
  опис «завантажувача»;
* **файл не підписаний** сертифікатом розробника і не має репутації.

Показово, хто МОВЧИТЬ: ESET, Kaspersky, Dr.Web, Avast, Bitdefender, Sophos,
Symantec, TrendMicro - тобто майже всі великі. З помітних лається лише
Microsoft Defender, вердиктом `Wacatac.B!ml` - це його узагальнена
машинна оцінка, відома величезною кількістю хибних спрацювань.

ESET окремо може дати `RiskWare.HackAV` - так він класифікує дзеркала
оновлень ЗАГАЛОМ, будь-чиї. Це не вірус: програма нічого не зламує й нічого
не змінює в системі.

Перевірити самому: [VirusTotal](https://www.virustotal.com/) - завантажте
туди файл і подивіться вердикти. Не подобається - не запускайте; вихідний
код я поки не відкриваю, тож вірити доводиться на слово, і це чесно сказати.
